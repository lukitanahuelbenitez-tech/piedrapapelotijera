Manual de usuario — Piedra, Papel o Tijera

1. Introducción

Este programa permite jugar a Piedra, Papel o Tijera contra la computadora y consultar el historial de partidas guardadas.

2. Requisitos

- Tener Windows y una terminal disponible.
- Contar con el ejecutable del programa.

3. Cómo iniciar el juego

Ejecutar el archivo "piedrapapelotijera.exe" desde la carpeta del proyecto.

4. Menú principal

El programa ofrece tres opciones:

1. Jugar partida: permite ingresar el nombre o apodo, elegir una jugada y conocer el resultado.
2. Ver historial: muestra las partidas guardadas en el archivo de texto.
3. Salir: cierra el programa.

5. Reglas del juego

- Piedra vence a Tijera.
- Tijera vence a Papel.
- Papel vence a Piedra.
- Si ambos eligen lo mismo, hay empate.

6. Guardado de datos

Cada partida se guarda en "src/historial_partidas.txt". Los registros pueden consultarse desde el menú, incluso después de cerrar y volver a abrir el programa, siempre que el archivo se conserve.
